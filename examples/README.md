# Ví dụ

`content.md` — mẫu file nội dung đặt trong folder Drive của bài viết.

Folder Drive của một bài nên trông như thế này:

```
AP-0007 - Tieu de bai/
├── content.md
├── 01-cover.jpg
├── 02-detail.jpg
└── 03-detail.png
```
